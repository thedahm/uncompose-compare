# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/thedahm/uncompose-compare/security/advisories/new).

If you can't use GitHub's reporting flow, email security@0x13.cc instead.

Please don't open public issues for security problems. Reports are handled on a
best-effort basis.

## Supported versions

`uncompose-compare` is pre-1.0 and versions independently of the rest of the
Uncompose family. Only the latest released version is supported: security fixes
land in a new release, not as a backport to an older one. Upgrading to the
latest `0.x` is the recommended remedy for any reported issue.
